동작 중 서버에서 실행 확인 일부 코드는 있으나 연결·등록이 안 됨 계획 아직 코드 없음 (점선 칸)

Hermes Agent 작업자 동작 중

요청 하나에 격리된 작업자 하나. 최대 8턴, 90초 제한. 도구 결과가 8,000토큰을 넘으면 앞부분을 잘라 낸다.

모델: Codex OAuth 동작 중

ChatGPT Plus 구독 로그인으로 gpt-5.6-luna를 쓴다. 요금 추가 없음. 로그인 토큰은 11-10 전에 다시 받아야 한다.

LangGraph 계획

코드에 있는 나머지 도구 일부

예약 4, 기억 2(저장·삭제), 웹 2, 메일 2 + 로그인 확인, 안드로이드 7(열기·클릭·입력·전송 등), n8n 2, 레시피 3(plan_execute 등), 기기 노드. 승인 흐름이 붙으면 연다.

↓
실행 환경도구가 실제로 손대는 곳

안드로이드 (ReDroid) 동작 중

Docker 안 Android 13. ADB는 서버 내부 주소에만 열림. uiautomator2로 카카오톡·배민을 조작한다.

브라우저 데몬 동작 중

Playwright를 계속 띄워 두고 지도·경로 검색에 쓴다. CDP도 서버 내부 주소만.

n8n 동작 중

Docker, 서버 내부 포트. 등록 워크플로는 health_check 1개. Agent는 미리 적어 둔 이름만 부를 수 있다.

로그인·안드로이드 화면 포털 필요할 때

noVNC 화면을 Cloudflare 임시 터널로 잠깐 열어, 휴대폰에서 직접 로그인·승인한다. 평소엔 꺼 둔다.

기기 노드 중계 일부

PC·휴대폰이 서버로 먼저 연결하는 구조라 집 공유기 포트를 안 연다. 서버 쪽은 떠 있고 등록된 기기는 0대.

Google 캘린더 계획

n8n 워크플로로 붙인다. Agent는 워크플로 이름만 알면 된다.

↓
저장재시작해도 남는 것

서버 파일 동작 중

agent.db(기억), schedule.json, recipes.json(route_now, n8n_status), heartbeat.json, 기기 노드 DB, 로그인 세션 프로필

Obsidian 기억 저장소 계획

기억을 마크다운 노트로 두고 Git이나 Syncthing으로 PC·휴대폰과 맞춘다. 사람이 직접 읽고 고칠 수 있다.

검색 색인 (RAG) 계획

Obsidian 노트를 sqlite-vec와 작은 다국어 임베딩으로 색인한다. 관련 노트 몇 개만 모델에 보낸다.

4. 보안 경계

밖에서 닿는 곳

  • Discord 봇 하나. 주인 ID만 응답
  • 로그인 포털은 필요할 때만 임시 터널
  • 기기 노드는 기기 쪽에서 나가는 연결만

안에서만 닿는 곳

  • MCP는 stdio, 네트워크 포트 없음
  • ADB, CDP, n8n은 서버 내부 주소
  • n8n 주소를 요청에서 받지 않음, 등록된 이름만
  • 쓰기 도구는 승인 없으면 거부
