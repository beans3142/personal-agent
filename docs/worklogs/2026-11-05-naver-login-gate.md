# 네이버 자동 로그인 게이트 — 2026-11-05

## 동작

서버 프로그램의 흐름은 서비스 요청 → 저장된 브라우저 세션 확인 → 필요할 때 로그인 → 캡차 감지 → 서버 ChatGPT 데스크톱 앱에 문제 이미지·질문 전달 → 구조화된 짧은 답 검증 → 같은 문제에 답 제출 → 로그인 재개 → 실제 메일함 확인 → 원래 작업 재개다. 사람이 답을 대신 입력하는 방식으로 구현하지 않았다.

현재 연결 지점은 MCP `auth_ensure`와 웹 메일 발송 도구의 내부 `AuthGate`다. IMAP 기반 `mail_list`·`mail_read`에 앱 비밀번호가 없을 때의 웹 조회 전환까지 구현한 것은 아니다.

## 위임과 실패 처리

- 비공개 `data/login-policy.json`에서 네이버·서버 데스크톱 Chat만 허용한다. 다른 사이트·다른 처리기로 범위를 넓히지 않는다. 배포 예제는 기본 비활성이다.
- 소유자가 시작한 유효한 요청만 자동 처리한다. 모델은 정책을 바꾸거나 승인을 부여할 수 없다. 요청당 캡차 처리는 최대 1회다.
- 캡차 답이 `null`이거나 형식이 잘못되면 제출하지 않는다. 실패하면 중지 상태를 디스크에 남겨 다음 일반 요청에서도 로그인·캡차를 반복하지 않는다.
- 소유자만 Discord에서 `네이버 로그인 재시도`로 중지를 해제하고 다시 확인할 수 있다. 정책 자체가 비활성인 경우 이 명령으로 허용 범위를 확대하지 않는다.
- 계정 보호조치는 `account_protected`, 휴대폰 인증 대기는 별도 상태로 처리한다. 계정 보호조치 해제와 본인 인증을 캡차로 대신하지 않는다.
- 원래 서비스 작업의 승인 규칙은 유지한다. 로그인 위임을 메일 발송 등 모든 작업의 자동 승인으로 확대하지 않는다.

## 수정한 오류

1. 별도 캡차 화면을 지난 후 로그인 폼으로 돌아왔을 때, 자격 증명을 한 번 다시 제출하도록 했다. 재제출은 무한 반복하지 않는다.
2. ChatGPT 앱에 숨겨진 이전 대화가 남아 있어도 현재 보이는 답변만 읽는다. 이전 답변을 새 문제에 사용할 수 있던 경로를 차단했다.
3. 캡차 이미지를 새로 요청하지 않고 이미 로드된 원본 픽셀을 복사한다. 불가능하면 이미지 영역 스크린샷으로 대체한다.
4. 네이버 전용 브라우저 프로필을 보존한다. 쿠키만으로 로그인 성공을 판단하지 않고 공식 메일 URL·인증 쿠키·실제 ‘메일 쓰기’ 화면을 함께 확인한다.
5. 로그인 미완료는 MCP 오류로 반환한다. 세션 확인용 문구의 공백 차이 때문에 실제 로그인 후에도 실패로 보고하던 오류도 수정했다.

## 실제 확인

- 배포용 프로그램 도구 호출에서 캡차 이미지 처리·답 제출·로그인 재개가 실행됐다. 작업자가 답을 입력하거나 제출 버튼을 대신 누르지 않았다.
- 계정 보호조치가 관측됐고 사용자가 해제했다. 잠긴 정확한 원인은 확인하지 못했다. 초기 답변 선택 오류와 여러 진단 접속은 있었으므로 원인을 외부 IP만으로 단정하지 않는다.
- 모델이 한 문제에서 `answer: null`을 반환한 실행에서는 답을 제출하지 않은 것을 확인했다.
- 수정 후 실제 받은메일함 접근, 브라우저 종료·재실행 후 로그인 유지, 프로그램 `auth_ensure`의 `ok` 반환을 확인했다. 저장된 세션 확인은 한 번의 측정에서 2.3초였다.
- 기존 시험 메일이 없는 것을 확인하고 실제 메일 발송 도구로 자기 자신에게 시험 메일을 1회 발송했다. 도구의 내부 로그인 게이트가 실행됐고, 보낸메일함에 정확히 1건이 나타났다. 발송 실행은 9.9초였다.
- 이 측정값을 일반 성공률이나 속도 보장으로 해석하지 않는다. 계정 보호조치·본인 인증·모델의 판독 불가 응답은 여전히 중지 사유다.
- 관련 검사 159개가 통과했다. 배포 후 실제 프로그램 도구의 `ok` 반환을 재확인했고 Discord 본체도 재시작했다. 전체 저장소 검사 통과로 확대 보고하지 않는다.

보호조치의 일반적인 사유와 해제 절차는 [네이버 공식 안내](https://help.naver.com/service/5640/contents/1117?lang=ko&osType=COMMONOS)를 참고했다. 이 안내만으로 이번 계정의 구체적인 원인을 확정할 수는 없다.
