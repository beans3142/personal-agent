# 분리된 작업 브랜치를 main으로 통합

> 2026-11-13 · 최근 구현 67개 커밋과 별도 실험 브랜치 5개 고유 커밋 통합

## 문제와 변경

실제 앱·서버 구현은 `feat/android-discord`, 예전 HTML 아키텍처 문서와 오프라인 토큰 실험은 `bench/token-experiments`에 남아 있었다. GitHub 기본 브랜치 `main`은 이전 상태여서 기본 README에서 최신 구조와 예전 설계 문서를 함께 찾기 어려웠다.

사용자가 모든 작업을 main으로 합치고 불필요한 브랜치를 정리하도록 요청했다. 최근 구현 브랜치는 main의 후손이므로 fast-forward하고, 실험 브랜치 고유 변경은 별도 merge로 보존한다. 충돌은 `.gitignore` 한 곳으로, 소유자 전용 플러그인·빌드 제외와 실험 작업 폴더 제외를 모두 유지했다.

README의 현재 SVG 아래에 전체 구성과 예전 HTML 문서 링크를 함께 추가했다. HTML은 2026-11-04 당시 설계 기록이므로 현재 구조와 구분해 표시했다. 원문을 최신 구조로 오인하게 바꾸지는 않았다.

## 정리 기준

원격 main에 두 브랜치의 끝 커밋이 포함된 것을 확인한 뒤 로컬·원격 브랜치 이름을 제거한다. 별도 실험 worktree는 같은 커밋의 detached 상태로 전환하고 폴더는 보존한다. 작업 폴더에 있을 수 있는 ignored 산출물이나 비공개 자료를 지우지 않는다. 서비스 재시작이나 재배포는 이 Git 정리 작업에 필요하지 않다.

## 셀프 인터뷰

**왜 실험 브랜치를 버리지 않았나요?**
예전 아키텍처 문서와 재현 가능한 오프라인 실험이 고유 변경으로 남아 있어 먼저 보존해야 했습니다.

**왜 두 작업 폴더를 모두 지우지 않나요?**
브랜치 정리와 로컬 산출물 삭제는 다릅니다. 사용자 요청을 충족하면서 자료를 잃지 않도록 브랜치 이름만 정리합니다.

**문서의 최신성은 어떻게 구분하나요?**
README에서는 현재 SVG를 먼저 보여주고, 과거 HTML에는 기준 날짜를 표시했습니다.

## 검증

병합된 상태에서 공개 테스트 1,052개가 통과했다. 기존 Windows→bash 경로 문제 테스트 1개는 제외했다. 비공개 플러그인 테스트는 이번 병합 검증 대상에서 제외했다. 공개 파일에서 서버 주소·인스턴스 ID·토큰 형태 검색 결과 추가로 발견된 값은 없었다.
