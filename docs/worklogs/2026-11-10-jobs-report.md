# 채용 보고서: 경력·병역특례 공고를 거르고 대기업·인턴·부트캠프를 따로 묶는다

> 2026-11-10 · 커밋은 아래 산출물 참고 · 게시된 공고 327건(대기업·공채 37, 인턴 58, 신입 216, 부트캠프 16), 제외 13건

## 무엇이 문제였나

소유자가 채용 보고서에서 짚은 문제는 다섯 가지였다.

- 원문이 404인 공고 링크가 그대로 보였다.
- 산업기능요원 공고와 경력직 공고가 섞여 있었다.
- 대기업 공채가 거의 보이지 않았다.
- 출처가 적었고 인턴·부트캠프가 없었다.
- 카드에 업무와 자격 요건이 없어서 내용이 부실했다.

## 왜 그런 일이 생겼나

- 404·410 응답을 "접근 실패"로만 표시하고 마감으로 처리하지 않았다.
- 예전에 직접 조사해 넣은 공고는 매일 상태만 다시 확인하고, 경력 조건 필터를 다시 거치지 않았다.
- "지원 예정" 상태의 공채는 보고서 대상에서 빠져 있었다. 대기업 공채를 모아 주는 출처도 없었다.
- 원티드·점핏은 상세 내용을 받아 놓고도 화면에 쓰지 않았다.

## 바꾼 것

보고서 수집·렌더링 코드는 공개 저장소 밖(`agent/private/brief/`)에 있어서, 여기에는 동작만 적는다.

- **같은 기준을 모든 공고에 적용한다.** 빼는 공고는 다음과 같다.
  - 병역특례(산업기능요원·전문연구요원) 공고
  - "N년 이상" 경력 요구, 연차 지정 공고
  - 해외 근무 공고
  - 백엔드와 거리가 먼 직무(임베디드·C++·로보틱스 등)
  - 404·410 원문(마감으로 처리)
- **출처를 추가했다.** 링커리어(대기업·공채, 인턴, 부트캠프·교육)와 사람인 신입 목록이다. 같은 공고가 여러 사이트에 있으면 카드 하나로 합친다.
- **카드 내용을 채웠다.** 주요 업무, 자격 요건, 우대 사항을 각 세 줄까지 보여주고, 공고 기술 중 소유자가 써 본 것을 표시한다. 이 비교는 모델 호출 없이 코드로 한다.
- **페이지 구성을 바꿨다.** "대기업·공채 / 인턴·채용연계형 / 신입·경력 무관 / 부트캠프·교육" 네 묶음으로 나눴다.
  - 겹치는 기술이 많은 순, 그다음 마감이 가까운 순으로 정렬하고 D-n을 붙인다.
  - 맨 아래에 제외한 공고와 이유를 보여준다.

## 확인한 것

- 비공개 보고서 테스트 58개가 로컬에서 통과했다. 서버에는 pytest가 없어 서버에서는 실행하지 않았다.
- 서버에서 보고서 생성과 Vercel 배포를 알림 없이 실행했고, 배포 상태는 deployed였다.
- 실제 `/jobs/` 페이지를 확인했다.
  - 네 묶음이 보인다.
  - D-n 표시 47개, 제외 목록 13건이 보인다.
  - 문제였던 병역특례 당근 공고는 제외 목록에 있다.
  - 모바일(375px)과 데스크톱에서 가로로 밀리지 않는다. 문서 전체 너비는 441px로 계산되지만, 실제 가로 스크롤은 0이었다.

## 아직 모르는 것

- SK하이닉스 공고가 없는 이유. 오늘 기준 링커리어 목록에 없었지만, 실제로 채용을 안 하는 것인지 그 사이트에 안 올라온 것인지는 확인하지 못했다.
- "백엔드와 거리가 먼 직무" 기준이 소유자가 원하는 범위와 맞는지.
- 잡플래닛과 직행은 넣지 않았다.
  - 잡플래닛: 비밀번호 로그인이 필요하고, 로그인 없이 쓰는 API는 403이었다.
  - 직행: robots.txt가 API 수집을 막는다.

## 셀프 인터뷰

1. **예전에 직접 넣은 공고까지 다시 거르는 이유는요?** 처음 넣을 때 조사 메모에 "경력 요건 미충족"이라고 적어 놓고도 계속 보여주고 있었습니다. 기준이 출처마다 다르면 보고서를 믿을 수 없어서, 모든 공고에 같은 필터를 적용했습니다.
2. **로그인이 필요한 사이트는 왜 빼나요?** 비밀번호를 대신 넣는 자동화는 만들지 않습니다. 또 사이트가 robots.txt로 막은 수집은 하지 않습니다.
3. **모델 호출이 늘었나요?** 아닙니다. 기술 비교와 분류는 모두 코드로 합니다.
