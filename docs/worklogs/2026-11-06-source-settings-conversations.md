# 출처 확인·수신 설정·작업별 대화 연결

2026-11-06. [전체 작업 목록](https://github.com/beans3142/personal-agent/issues/6)의 2~5번을 구현하고 배포했다.

## 채용·행사

기업 공식 목록/API와 채용 플랫폼을 수집하는 경로를 프로그램으로 만들었다. 네이버33건, 네이버클라우드2건, 카카오34건, 토스494개 직무 공고, 점핏796건을 확인했다. 원티드는 5개 직무 필터의 목록과 개별 상세를 읽었다. 필터 사이에 중복이 있으므로 이 수를 합산해 전체 공고 수로 쓰지 않는다.

사람인·잡코리아·캐치·인큐커리어는 검색 페이지 접근 범위로 표시한다. 전체 목록을 다 읽은 출처와 일부만 확인한 출처를 구분한다. 저장된103개 기록 중 접수 상태 확인62개, 미확인29개, 마감5개, 차기 후보7개다. 이번 조사에서 처음 기록한 후보33개는 '새로 게시된 공고33개'라는 뜻이 아니다.

현재 동일 공고의 기업 공식·플랫폼 복수 출처 일치까지 확인한 건은0개다. 따라서 교차 검증 미확인을 그대로 표시한다. 채용 사이트 한 곳에서 확인한 값을 여러 곳에서 검증한 것처럼 쓰지 않는다. 일부 상세 접근과 연봉·개인 적격 판단은 미확인이다. 이 수집은 전체 채용시장 전수 조사나 지원 적격 보장이 아니다.

행사는 목록의 접수 마감과 행사일을 구분하고 주최 페이지를 다시 확인한다. 정보를 확인하지 못하면 이전 목록 정보라는 표시를 유지한다. 추적용 URL 매개변수가 달라도 같은 항목으로 비교하며, 앞서 소개한 항목과 내용 변경을 숨기지 않고 표시한다.

## 수신 설정

5종을 각각 켜고 끄는 설정은 항상 켜진 중계 서비스의 저장소 하나를 사용한다. Discord 버튼·본인 인증된 웹·본체의 자연어 도구가 같은 값을 읽고 쓴다. 웹 로그인 링크는15분간 한 번만 쓸 수 있고 세션 쿠키는30일이다. 로그인 비밀값의 원문은 서버 DB에 저장하지 않는다.

매일09시(KST)에 일간·기술 블로그·채용·행사를, 금요일09시에 주간 트렌드를 발송한다. 보고서마다 전송 전 이력을 남기며, 결과가 불확실한 발송은 자동으로 반복하지 않는다. 켜기/끄기는 수신 여부이며 웹 기록 삭제는 아니다.

웹에서 설정 변경 뒤 공통 API와 새 브라우저 세션이 같은 값을 읽는지 확인했다. 다른 사용자의 Discord 버튼 조작은 거부하는 테스트가 통과했다. 본인 DM에 영구 설정 버튼을 게시했다. 소유자가 실제 Discord 클라이언트에서 버튼을 누르는 화면까지 자동 조작한 시험은 아니다.

## 대화 연결

새 대화는30일 동안 작업별로 저장한다. 이어지는 질문과 새 주제를 구분하고 판단이 애매하면 선택 화면을 제공한다. Discord 답글도 기록된 작업과 연결한다. 일반 질문과 Hermes 도구 경로에 같은 작업 문맥을 전달한다.

DM에서 공개 작업을 이어갈 때는 별도 분기를 만들며, 그 뒤의 비공개 메시지를 원래 공개 작업에 추가하지 않는다. 보관 기간과 모델 입력량을 구분해 최근12개 메시지·약6,500자 이내를 선택한다. 오래된 주제는 범위가 제한된 검색으로 찾는다. 구형 기록은 시각 정보가 없어 자동으로30일 이력이라고 간주해 이관하지 않았다.

실제 모델로 'HTTP 캐시 설명 → 더 풀어서 설명 → 피타고라스 질문'을 실행해 앞의 두 질문이 이어지고 마지막 질문이 새 작업이 되는 것을 확인했다.30일 만료와 공개/비공개 경계는 가상 시계·범위 테스트로 검증했다. 주제 분류에는 별도의 모델 호출이 필요하며, 기존 응답 통계와 완전 합산하는 관측 개선은 남아 있다.

## 자연어 전원 요청

모델은 현재 요청을 해석하고 등록된 도구를 호출한다. 실행 계층은 현재 메시지의 대상과 종료 의도를 확인하고 등록되지 않거나 다른 PC를 선택한 요청을 거부한다. 설명·인용·가정·부정·나중 실행 조건을 즉시 전원 명령으로 처리하지 않는다. 임의 셸 명령은 받지 않는다.

PC 종료는60초 대기·취소를 유지한다. 서버 종료는30초 뒤 요청하며 모델의 추가 답변을 기다리지 않고 접수 결과로 응답한다. 도구의 접수·예약·신호 전송을 실제 전원 종료/부팅 성공과 구분한다. 같은 요청의 재호출은 저장된 이력으로 중복을 막는다.

실제 모델과 MCP 경로에 가짜 종료 도구를 연결했다. 도구 호출2회 중 접수 영수증1개가 확인됐고 추가 모델 답변 전에 끝났다. 실제 PC·서버 전원 조작은0회다. 물리적 종료/켜기 성공은 여전히 사용자 기기에서 별도 확인할 범위다.

## 검증과 기록

- 기능 회귀 테스트197개가 통과했다. 이후 대상 이름 결합 조건은 관련 테스트54개와 전원 조건24개로 추가 확인했다.
- 실제 웹에서 본인 인증·공통 설정 저장·새 브라우저 세션 유지, 모바일 보고서/출처 범위/설정 링크를 확인했다.
- 모델→설정 도구 저장, 모델→대역 MCP 전원 접수, 실제 모델의 대화 연결을 확인했다.
- 출처 자료와 개인 설정·인수인계는 공개 Git에 올리지 않는다.
