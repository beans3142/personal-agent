# 카카오톡 검색·전송 경로 수정 — 2026-11-05

사용자가 이전 요청의 미전송을 확인했다. 해당 요청은 화면 조작마다 모델을 호출하다 12회 한도에 걸렸다. 한도를 높이는 대신 기존 프로그램 전송 경로를 확장했다.

## 변경

- `카카오톡 도구 활용해서 이름에게 …라고 보내줘`, 따옴표로 지정한 본문 등 명확한 문장은 모델을 거치지 않고 처리한다. `반갑다고`처럼 본문 작성이 필요한 표현은 모델이 해석한다.
- 태블릿의 채팅 목록 검색과 대화 내용 검색을 구별한다. 검색 결과가 하나이고 열린 개인 채팅 제목이 정확히 일치할 때만 입력·전송한다. 친구 프로필을 거치는 경우 `1:1 Chat`을 사용한다.
- `kakao_send`로 검색부터 새 발신 말풍선 검증까지 묶었다. 모델 경로에서도 원시 Android 조작 대신 이 도구를 우선하도록 했다. 기존 소유자 승인 절차는 유지한다.
- 기존 초안은 덮어쓰지 않는다. 전송 전 상태를 디스크에 기록하며, 결과가 불확실하면 재시도하지 않는다. 같은 소유자 요청에서 확인된 전송도 반복하지 않는다. 기록에는 상대 이름·메시지 대신 상태와 해시를 저장한다.
- 오타 후보 검색은 별도 기능이다. 전체 이름과 앞·뒤 두 글자로 검색한 결과를 비교해 최대 3개 이름을 반환한다. 후보가 생겨도 바로 전송하지 않는다. 프로그램 경로의 후보 안내는 소유자 DM으로만 보낸다.
- 검색 결과의 프로필 사진을 자기 계정으로 오인하지 않도록, 자기 채팅 이동 전에 전역 검색 화면에서 빠져나온다.

## 확인한 결과와 한계

- 실제 대상의 이름을 검색해 정확한 개인 채팅방을 여는 것까지 확인했다. 해당 상대나 단체방에는 시험 메시지를 보내지 않았다.
- 직접 게이트웨이 호출로 나와의 채팅에 시험 메시지를 전송하고 새 말풍선을 확인했다. 13.6초, 모델 호출 0회였다. 이 한 번의 결과를 일반적인 속도나 성공률로 확대하지 않는다.
- 첫 Discord 웹 시험은 검색 화면에서 자기 채팅으로 돌아가는 단계에서 실패했다. 전송 전에 멈췄다. 이후 검색 화면 이탈 및 입력 활성화 처리를 보완하고 재배포했다. 보완 후의 Discord 실전 성공은 아직 확인하지 않았다.
- 오타 후보 검색의 실제 시험은 후보 0개였다. 코드와 단위 검사만으로 실제 오타 복구 성공을 주장하지 않는다. 검색 결과의 접근성 구조와 검색어 축약 방식은 추가 검증이 필요하다.
- “특정 사람이 있는 최신 채팅방” 자동 선택은 구현되지 않았다. 방 제목만으로 참여자를 추정하거나, 확인되지 않은 활동 시각으로 최신 방을 고르지 않도록 지침을 넣었다. 실제 참여자·시각 조회가 필요하다.
- 관련 검사 115개 통과. 게이트웨이, 검색·중복 방지, 자기 채팅, MCP, Hermes 연결, Android 조작 검사를 실행했다. 전체 저장소 검사를 통과했다고 보고하는 것은 아니다.
