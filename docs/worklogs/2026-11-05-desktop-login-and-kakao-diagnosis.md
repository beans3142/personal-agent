공식 설치 안내: [ChatGPT Linux app](https://learn.chatgpt.com/docs/linux/linux-app).

## 완료하지 못한 사항

- 실제 네이버 로그인 시험 결과는 `login_failed`였다. 메일함 로그인 및 자기 자신에게 메일 보내기는 성공으로 기록하지 않는다. 원인이 정답, 계정 상태, 후속 인증 중 무엇인지는 현재 결과만으로 확정할 수 없다. 추가 제출은 하지 않았다.
- 실제 Android 기기 설치는 사용자가 나중으로 미뤘다. PC 기기 노드도 설치되지 않았다. 서버 노드 시험을 실제 PC↔휴대폰 연결 완료로 간주하지 않는다.

## 12:49 카카오톡 요청 중단 진단

실행 기록의 시작은 12:48:57, 종료는 12:49:52다. 종료 사유는 `max_iterations_reached(12/12)`다. 도구 검색·설명 조회를 포함해 모델 호출 한도 12회를 소모했다. 카카오톡 실행 이후 화면 조회, 클릭, 입력이 있었으며 해당 실행 구간에 기록된 도구 오류는 없다.

따라서 이번 중단의 직접 원인은 시간 초과나 앱 차단으로 확인된 것이 아니라 모델 호출 횟수 상한이다. 일반 화면 조작으로 메시지 작업을 수행하면서 조회와 조작마다 모델 판단이 필요해 한도를 소모했다. 표시 문구는 여러 실패 사유를 묶기 때문에 실제 원인을 설명하지 못했다.

현재 화면에서는 요청 문구를 확인하지 못했다. 마지막 클릭의 대상과 전송 결과 영수증이 보존되지 않아 실제 전송 여부를 확정할 수 없다. 원문, 상대 이름, 다른 대화 내용은 이 문서에 저장하지 않았으며 메시지도 재전송하지 않았다.

후속 개선 후보는 종료 사유의 정확한 전달, 개인정보를 제외한 단계별 결과 기록, 수신자 확인→입력→전송→검증을 묶는 전용 도구다. 이번 진단에서 이를 구현하거나 호출 한도를 늘리지는 않았다. 한도 증가만으로 해결하면 지연과 토큰 사용이 늘 수 있다.
