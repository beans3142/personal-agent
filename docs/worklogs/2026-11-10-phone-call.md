# Discord에서 "○○에게 전화 걸어줘"로 폰이 전화를 건다

> 2026-11-10 · 커밋은 아래 산출물 참고 · 운영 중계 서버에서 가짜 Termux 명령으로 3가지 경우(바로 걸기, 후보 고르기, 없음)를 끝까지 확인

## 무엇이 문제였나

소유자는 휴대폰 ↔ 서버 ↔ 데스크톱을 양방향으로 쓰고 싶어 했다. 그 첫 기능으로 PC에서 "○○에게 전화 걸어줘"라고 보내면 실제 폰이 전화를 거는 것을 원했다. 그런데 기존 노드 프로토콜은 작업 결과를 "성공/실패" 상태로만 돌려줄 수 있어서, 연락처 후보 같은 데이터를 서버로 보낼 통로가 없었다.

## 고를 수 있던 방법

| 방법 | 장점 | 버린 이유 또는 고른 이유 |
| --- | --- | --- |
| 무선 디버깅으로 폰 화면을 조작해 다이얼러 누르기 | 앱 조작으로도 넓힐 수 있다 | 화면 잠금과 사용 중 충돌이 생기고, 전화 하나에 너무 많은 단계가 들어서 버림 |
| Termux:API의 연락처 목록과 전화 걸기 명령 | 화면 조작이 필요 없고 권한 범위가 좁다 | 고름 |
| 메인 서버(Hermes)에 붙이기 | 모델이 자연어를 해석한다 | 메인 서버는 쉬면 꺼지므로, 항상 켜진 전원 봇에 규칙 기반 명령으로 붙임 |

## 바꾼 것

- `deploy/device-node.py`의 `phone_call`:
  - 폰이 자기 연락처를 직접 검색한다.
  - 이름이 정확히 한 명과 맞으면 바로 전화를 건다.
  - 일부만 맞는 사람이 여럿이면 후보와 5분짜리 일회용 선택 코드를 돌려준다.
  - 8자리 미만 번호(긴급번호 등)는 걸지 않는다.
  - 번호는 가린 형태(010-****-5678)로만 폰 밖으로 나간다.
  - 노드 설정에 `allow_phone_call`이 켜져 있을 때만 동작한다.
- 노드 프로토콜: `ack`에 2KB 이하의 `result`를 실을 수 있게 했다. `jobs.result` 열을 추가했다. 결과를 보내지 않는 기존 PC 노드도 그대로 동작한다.
- 전원 봇(`agent/pc_control.py`, `agent/phone_discord.py`, `agent/power_bot.py`) 명령:
  - `폰 등록 [이름]`: Termux 설치 명령을 DM으로 보낸다. 등록 코드는 15분 동안 한 번만 쓸 수 있다.
  - `○○에게/한테/께 전화 걸어줘`: 전화를 건다. 후보가 여럿이면 본인만 누를 수 있는 버튼을 띄운다.
  - `폰 등록 해제`: 등록된 폰을 해제한다.
- `deploy/install-phone.sh`: Termux에서 실행하는 설치 스크립트. 하는 일은 패키지 설치, Termux:API 확인, 연락처 권한 확인, 서버 등록, 내려받은 프로그램의 sha256 검증, 백그라운드 실행이다. Termux:Boot와 `.bashrc`에 자동 시작을 걸어 둔다.
- 메인 게이트웨이는 전화 명령을 무시한다. 같은 봇 토큰을 쓰므로, 응답은 전원 봇만 한다.
- `agent/hermes_runner.py`: ChatGPT 로그인 만료(`model_auth_failed`)일 때도 도구를 쓰기 전이면 Claude로 다시 시도한다.

## 확인한 것

- 로컬 전체 테스트 776개가 통과했다. 그중 전화 기능 테스트가 31개다.
- 운영 전원 봇에 배포했다. 설치 스크립트 주소는 HTTP 200으로 열렸고, 배포된 프로그램의 해시가 중계 서버 응답과 같았다.
- 운영 중계 서버를 실제 HTTPS 경로로 끝까지 시험했다. 시험용 폰 노드를 등록하고, Termux 명령 대신 가짜 스크립트를 썼다.
  - 정확히 맞는 이름: 바로 걸림. 다이얼된 번호가 맞았다.
  - 일부만 맞는 이름: 후보 2명이 돌아왔다.
  - 없는 이름: `not_found`가 돌아왔다.
  - 시험이 끝난 뒤 시험용 폰 등록을 해제했다.
- 메인 서버를 켜서 게이트웨이와 Claude 전환을 배포했다. ChatGPT는 11/12 16:57까지 사용량 한도에 걸려 있었고, 같은 요청이 Claude로 처리되는 것을 확인했다.

## 아직 모르는 것

- 실제 폰에서의 동작. Termux:API 권한 창, 잠긴 화면에서 전화가 걸리는지, 배터리 최적화가 노드를 멈추는지는 기종에 따라 다르다. 소유자가 폰에서 설치한 뒤에 확인해야 한다.
- Windows "휴대폰과 연결"을 함께 쓸 때 통화 음성이 PC로 넘어오는지.

## 셀프 인터뷰

1. **왜 서버가 연락처를 받지 않나요?** 이름이 겹칠 때 고르는 데는 이름과 가린 번호만 있으면 충분하기 때문입니다. 실제 번호는 폰에만 있고, 서버는 5분짜리 선택 코드만 다룹니다.
2. **부분 일치에서 바로 걸지 않는 이유는요?** "철수"로 "김철수(회사)"에게 걸리면 되돌릴 수 없습니다. 바로 거는 것은 저장된 이름과 정확히 맞는 사람이 한 명일 때뿐입니다.
3. **메인 서버가 꺼져 있으면요?** 전화 요청은 항상 켜진 전원 봇이 받습니다. 그래서 메인 서버 상태와 관계없이 동작합니다.
