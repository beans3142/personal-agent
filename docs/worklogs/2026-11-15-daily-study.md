# 매일 공부 자료 세 개: 트렌드, 백엔드 기초, 공고 기반 면접 질문

> 2026-11-15 · 브리핑에 "데일리 스터디"를 더했다. 주제는 코드가 고르고, 모델은 설명만 쓴다. 하루 모델 호출 3회, 같은 날 재실행은 0회

## 무엇이 문제였나

브리핑은 소식과 공고를 보여 줄 뿐 공부로 이어지지 않았다. 매일 최신 트렌드 하나, 백엔드 기초 하나, 면접 대비 하나를 배경부터 면접 질문까지 정리한 자료가 필요했다.

## 고를 수 있던 방법

| 방법 | 장점 | 버린 이유 또는 고른 이유 |
| --- | --- | --- |
| 모델에게 주제 선정까지 맡김 | 구현이 짧다 | 매일 비슷한 주제가 반복되고, 왜 그 주제인지 근거가 없다. 버림 |
| 실제 면접 후기 사이트에서 질문 수집 | 진짜 기출 | 후기 사이트는 로그인이나 자동 수집 차단이 걸려 있다. 버림 |
| 주제는 코드가 고르고 설명만 모델이 쓴다 | 선정 근거가 남고 토큰이 적다 | 고름 |

## 바꾼 것

- **오늘의 트렌드**: 그날 수집한 GitHub·기술 블로그 소식 중 내 기술·관심 영역과 가장 가까운 것을 고른다. 최근에 다룬 링크는 건너뛴다. 소식을 요약하지 않고, 그 소식을 이해하는 데 필요한 개념을 가르친다.
- **백엔드 기초**: 격리 수준, 인덱스, 락, 캐시, MQ, 인증, 분산 트랜잭션 등 52개 주제 목록을 순서대로 하나씩 다룬다. 다 돌면 처음부터 다시 시작한다.
- **공고 기반 면접 질문**: 그날 살아 있는 공고들이 요구한 기술을 세어 가장 많이 요구한 기술을 고른다. 동률이면 내게 없는 기술로 판정된 공고가 많은 쪽을 먼저 고른다. 최근 14번 안에 다룬 기술은 건너뛴다. 공고의 요구 문장을 근거로 질문을 만든다. 페이지에는 "실제 면접 기출이 아니다"라고 밝힌다.
- 각 자료의 구성: 한 줄 정의, 왜 생겼나, 동작 단계, 예시, 흔한 오해, 면접 질문 3개(답변 핵심과 꼬리 질문), 내 경험과 연결, 다음 주제.
- 내 경험 연결에는 포트폴리오의 공개 사실만 넘긴다. 회사 내부 수치가 담긴 사실은 모델에게도 보내지 않는다.
- 트랙별로 그날 결과를 저장한다. 같은 날 다시 돌려도 모델을 부르지 않는다. 한 트랙이 실패하면 나머지는 그대로 싣고, 실패한 주제는 다음 날 다시 시도한다.
- 모델은 ChatGPT를 먼저, Claude를 다음으로 쓴다.
- 사이트 메뉴에 "스터디"를 추가했다. 매일 DM은 설정 페이지에 스위치가 생기기 전까지 기본으로 켜 둔다.

## 확인한 것

- 관련 테스트 8개를 먼저 추가했고, 브리핑 비공개 테스트 78개가 통과했다.
- 서버에서 그날 데이터로 실제 생성 1회: 세 자료 모두 생성, 160초, 실패 0. 주제는 AI 코딩 에이전트 워크플로(트렌드), 트랜잭션 격리 수준(기초), Python 백엔드(공고 94건이 요구)였다.
- 생성된 격리 수준 설명을 직접 읽었다. 네 수준의 차이, 표준과 PostgreSQL 구현의 차이까지 틀린 곳이 없었다. 내 경험 연결은 "제시된 경험만으로 Python을 직접 썼다고 말할 수는 없다"처럼 과장하지 않았다.
- 배포 페이지에서 카드 3개와 질문 9개를 확인했다. 375px 폭에서 가로 넘침은 없었다.

## 틀린 지점

- 처음 구현은 재실행 때 "오늘 이미 다룬 주제"가 기록에 들어가 있어 다른 주제를 새로 골랐다. 그래서 같은 날 모델을 또 불렀다. 트랙별 그날 결과가 있으면 다시 고르지 않게 고쳤다.
- 공부 자료가 없던 옛 날짜에도 빈 페이지가 만들어졌다. 자료가 있는 날만 만들게 고쳤다.

## 아직 모르는 것

- 공고 기반 주제는 공고에 많이 나오는 기술을 고르므로 Python처럼 내 주력이 아닌 기술이 뽑힐 수 있다. 일부러 막지 않았다.
- 실제 면접 기출은 쓰지 않는다. 기출 출처를 붙이려면 공개된 출처를 따로 찾아야 한다.

## 셀프 인터뷰

**왜 주제를 모델에게 고르게 하지 않았나요?**
모델에게 맡기면 무엇을 왜 골랐는지 남지 않고, 비슷한 주제가 반복됩니다. 커리큘럼 순서, 공고 요구 빈도, 내 기술과의 거리는 코드로 계산할 수 있어 토큰도 들지 않습니다.

**"면접 질문"이라면서 기출이 아닌 건 문제 아닌가요?**
그래서 페이지에 "공고 요구사항에서 뽑은 예상 질문"이라고 적었습니다. 질문의 근거는 그날 공고의 요구 문장이고, 어느 공고에서 왔는지 링크를 같이 둡니다.

**하루 비용은 얼마나 드나요?**
모델 호출이 하루 3회입니다. 그날 결과를 저장하므로 같은 날 재실행해도 늘지 않습니다.
