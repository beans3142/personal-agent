# README에서 내부 운영 메모 분리

> 2026-11-13 · README 작성 범위를 AGENTS.md에 명시

## 변경

사용자가 README에 내부 계정 시험 상태와 설정 변수 목록을 나열하지 말라고 요청했다. 인용한 시험 전 문구는 현재 main README에는 없었다. 대신 최근 덧붙인 A/B 실험 플래그·측정 명령·효과 수치 문장을 정리했다. 해당 근거는 기존 작업 기록에 남아 있다. 설치·환경변수·서비스·테스트 안내는 `docs/setup.md`로 옮기고 README에서는 링크한다.

AGENTS.md에는 README를 소개·기능·사용 예시·아키텍처 중심으로 쓰며, QA·배포·실험 메모는 작업 기록, 계정별 상태는 비공개 HANDOFF에 둔다는 규칙을 추가했다. 미검증 기능을 검증된 것으로 바꾸지 않는다는 기준도 유지한다.

## 확인

문서 변경만 있으므로 실행 테스트는 추가하지 않았다. diff 공백 검사와 문서 링크 대상 존재 여부를 확인했다.

## 셀프 인터뷰

**시험 사실을 숨기나요?** 아니요. 검증 근거를 작업 기록에 보존하고 사용자에게 필요한 실제 제약은 남깁니다.

**설정값 안내는 어디로 가나요?** 별도 설치·설정 문서로 옮깁니다.

**재발은 어떻게 막나요?** 저장소의 모든 코딩 에이전트가 읽는 AGENTS.md에 README 범위를 명시했습니다.
